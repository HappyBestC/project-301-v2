# MAS科研实验组织约定

当前只有目录与记录规范，没有新增方法、Baseline实现、消融实验或结果。

| 目录 | 用途 |
|---|---|
| scenarios/ | 将来版本化的固定场景引用、资源初态与可控变量 |
| baselines/ | 将来对照方法的配置、实现版本与运行说明 |
| ablations/ | 将来逐项关闭模块的受控配置；与原方法明确配对 |
| results/ | 将来真实实验的run目录；不提交密钥，输出须带来源 |

每个实验记录必须包含scenario_id、唯一run_id、模型名与版本、两个Agent/Provider配置与Prompt SHA（不含凭据）、资源初始条件、伤情/患者及规则版本和SHA、方法或Baseline版本、随机种子（不支持时明确null与原因）、执行时间/环境、结果与评价指标、失败日志、动作/资源事件轨迹及终止原因。区分Mock/固定fixture/真实LLM/真实Pulse证据；失败、缺测和未运行不能填成成功或零值。

结果只能来自实际运行；记录执行成功、资源分配成功、机制成立、疗效及安全各自的判断。后续重规划需保留plan/action/request ID与资源版本以便归因。新研究范围、资源参数和算法不在本轮创建。
