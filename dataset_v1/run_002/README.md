# run_002：阵地受伤场景

由 `dataset_v1/run_001` 派生，仅受伤地点不同：A → F1、B → F2。
16 名伤员的伤情、受伤时刻和候选方案保持不变；`arrival_time_min` 表示受伤时刻。
本场景使用 `config/medical_resources_v1_1`，阵地没有资源，也不允许启动处置。

观测逐字节沿用 run_001 的 Pulse 采样（受伤后约 2 分钟），与执行桥重新推演的
引擎不是同一次仿真；第 10、20 分钟受伤的伤员也使用该份观测，沿用 V1 已知简化。

仅复制规格要求的两个患者索引、动作模板和 16 个观测文件。索引中的原始证据引用
原样保留，`raw/`、`evaluation_evidence/` 等不随本场景复制。

本场景没有离线回放排程，offline 与 native_replay 均拒绝运行；V1.1 不进行该场景的
端到端排程或真实模型调用。
