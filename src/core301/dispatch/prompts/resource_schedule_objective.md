转运时序

每个transports任务填完整时刻：
load_start_min = start_min + travel_min[车辆当前位置][pickup]
depart_min = load_start_min + loading
arrive_min = depart_min + travel_min[pickup][destination]
handoff_end_min = arrive_min + handoff
end_min = handoff_end_min + turnaround
当前loading=3、handoff=5、turnaround=5分钟；具体仍以输入为准。departure_location必须等于车辆本次真正出发位置。当前校验器要求空驶start_min也不早于被接患者arrival_time_min。所有阶段及车辆end_min不得越过演示范围。
