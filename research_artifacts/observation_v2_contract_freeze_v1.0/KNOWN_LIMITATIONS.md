# 已知限制及适用边界

- N1 保持 NON_BLOCKER：Schema 允许部分 Python 拒绝的 null 结构，Evaluation 诊断字典未完整表达静态白名单；两项失败测试、断言及非零退出码保留。任何正式使用都必须经过 Python 语义校验、可信宿主授权及投影。
- 现有隔离适用于冻结只读数据和可信宿主；未接入普通 Agent/Runtime，不能把研究授权对象当作外部请求认证。评价器真值不得进入 PatientObservation。
- 15 项包括五基础、十条件；旧七类单伤 CSV 缺 COHb/Na，不得填零。ICP 不纳入 V2 核心，V1 保持。
- COHb 是 g/dL 质量浓度而非百分比；Na 为 Aorta/Sodium/Molarity、mEq/L。临床采血、资源、周转延迟和正式结果获得链路尚未接入。
- 源快照稀疏，Action 诊断可能 unavailable；动作 accepted 不证明机制成功，源不在列表不证明已控制。共享生理改善不能独自归因于某一复合成分。
- 同刻动作顺序明确不可确定；同刻完全相同生理采样只在历史读取层作可审计合并，原始统计不变。事件使用步后观测时刻，窗口前持续时间保持。
- B1 已解除不扩大固定 Profile 风险接受，不代表整体治愈或临床安全认证。
- 冻结标识位于版本清单，不把实现 Literal/x-version 改为新运行时版本；源码快照仍保持候选名称。版本迁移和 Runtime 接入另行审批实施。
- 当前归档依赖项目原路径/同结构根及记录的 Python 环境，大型原始证据/引擎不复制；不得称为独立发行包。SHA 提供内容完整性，不提供外部签名信任根。
