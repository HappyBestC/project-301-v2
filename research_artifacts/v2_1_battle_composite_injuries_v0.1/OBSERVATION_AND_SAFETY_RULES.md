# V2.1 预先声明的观测及安全规则 v0.1

所有试验均由研究宿主显式授权。公开观测复用既有 13 项合法 V2 字段和 ObservationProjector；原生诊断另列来源，不伪装临床已取得的检查。新增胸膜压力是绝对压力，不当作跨肺压；总流体量是原生 Tissue 读数，COHb/Aorta CO、血钠、积血及流量保留原值。缺值记录为 null，不插补。未施加胸管时的流量不可用不伪造为零；已执行后的关键缺测拒绝判定。

逐个 0.02 秒原生步读取 ActiveEvents，事件集合变化时记录带原生时刻及持续时长的完整事件快照；每秒保存全部公开观测和诊断。原生日志保留包括警告。五种既有危重事件 IrreversibleState / CardiacArrest / CardiovascularCollapse / CriticalBrainOxygenDeficit / HypovolemicShock 立即停止仿真并判失败。

阶段一要求源身份与数值机制证据并存、关键读数完整且没有引擎崩溃或危重停止。非危重异常不等于共存失败，但不能因此获得安全准入。

研究治疗对照允许观察固定伤情造成的非危重异常，以形成可审查证据；这不是受限 Runtime 正式准入或新风险豁免。全部异常须按分支、首次时刻及终点状态审查。生理周期事件 StartOfCardiacCycle / StartOfInhale / StartOfExhale 不属于病理事件，但仍记录。任何新的或未获授权的病理事件、血胸负残余数值解释、新的高钠轨迹均阻断正式准入。V2.0 风险批准不适用于 V2.1。

局部机制判定：A 救助须对 A 的目标机制提供真实源控制/设备交付及相对 Control 的改善，B 同理；AB/BA 均需分别评估两者，不以整体某一个指标替代。氧疗须同时审查 PaCO₂、pH 与高氧事件；体液支持须读真实流体量及血流动力学，不将袋分配等同注入量。联合治疗与 Control、A、B 的终点及轨迹一起输出，不将“全部 Action accepted”记为通过。

独立重复比较相同固定分支全轨迹，以项目既有 1e−7 精度检查确定性，不能把它当作临床阈值。正式准入须有机制、对照、联合治疗、资源/幂等/异常隔离、真实 Runtime E2E、回归和显式研究安全处理的完整证据链；缺任一项保持 BLOCKED/PENDING。

## 工程分类补充（不覆盖原始分析）

初版 `treatment_review.json` 的安全字段保守地将任何病理事件标记为需要审查，它不执行准入。正式分类必须区分已建立伤情的目标事件与额外风险：仅 `Hypoxia` / `Tachycardia` 若已在治疗前出现、联合治疗终点均消失，可沿用 V2 对目标机制改善的事件解释。并非忽略事件，更不允许它们持续到终点或在治疗后首次新增。所有其他病理事件仍需独立风险审查。严禁沿用单伤高钠批准或把 BrainOxygenDeficit 归入这一目标事件集合。局部机制规则不变；临床安全仍不评估。

Condition 初始化内部包含原生稳定化，研究时钟归零时已有事件持续时长可能非零。例如脱水初态 Na=148.297412 mEq/L，Antidiuresis 已累计833.48秒；不能把首次研究采样视为真实发生时刻。原生初始化日志完整保留，额外扫描所有42份日志中的既有危重事件，包含稳定化阶段；`validation/critical_event_log_audit.json` 未发现这五类危重事件。其余已存在事件不删除，仍须风险审查。
