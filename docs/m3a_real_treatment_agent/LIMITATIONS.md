# 当前限制与后续边界

先前预检因三个配置项缺失阻断；用户填写后，新 run m3a-real-agent-001 已用 gpt-6-sol 完成真实决策、原生控源、资源释放、真实观测和正式评价入口。目前无阻止本场景运行的配置问题。模型名称与 usage 来自所配置服务的原始响应，不额外声称底层供应商身份。

只开放 StandardMale / RightLeg external_hemorrhage / .4 / 单个 control_external_bleeding；本轮 schema 不等于十二动作通用 LLM 规划器。本次完成真实实验只验证单候选动作接线能力。调度继续是 FixedDispatchProvider；不声称两个真实 LLM 协作。

资源仍为研究 medic 令牌，并非临床人员规格或操作时长。系统仍单进程共享内存，无跨进程恢复、抢占、补给或资源反馈重规划。未知执行必须保留隔离；不复用 run 目录，不自动重新提交治疗。

Agent 只获得五个基础测量。十五指标未全 Runtime 激活；后端十三字段采样和内部诊断不自动授予模型。既有 StandardMale 与独立 Soldier / Control 证据不匹配仍存在：本次成功运行的正式评价实际为 NOT_EVALUABLE，不能等同 I 或 E/P。本轮未改变评价规则、采样窗口或匹配资格。

旧 26 个 native integration 用例不在本次非原生回归范围。Mock HTTP 与模拟 Pulse 测试不能证明远端模型兼容、真实 Pulse 治疗或疗效。

M3-A 单场景验收已通过，可以进入下一阶段双伤员共享资源研究的设计与开发；这不等于双伤员能力已经通过验收。M3-B 仍需独立的双患者时钟/生命周期、资源竞争协议与实验。本轮未实施 M3-B/C，完成后停止。
