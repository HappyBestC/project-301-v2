# 范围与限制

本轮只完成 M3-C1 一次排序决策与执行因果接入。相同 StandardMale、RightLeg 外出血、内部 Severity .4 的对称患者只能验证接线与资源/身份因果，不能证明医学排序优越性。

仍未实现：M3-C2、资源反馈驱动多轮重规划、动态治疗时序、第二个真实 Treatment Agent、多动作复杂排序、跨机账本持久化、Worker重启恢复、资源优化与统计比较。没有新增患者、复合伤、动作、剂量或Unity接口。

等待患者在181秒可以重新获配资源，但超过冻结180秒治疗时点，仍必须取消未用预留而不治疗。本轮不要求两个患者都完成治疗。释放沿用首次181秒采样的源机制确认，不代表临床治疗耗时。

两个 spawn Worker 独立持有状态；全局屏障只在两者确认同一时间后处理事件。单边推进故障停止全局运行并保留Unknown/隔离，不声称可原子回滚。

正式评价继续受 StandardMale 与独立 Soldier 证据不匹配限制，允许 NOT_EVALUABLE，不能伪造 E/P/I。26项旧原生 integration 不等于本轮三个明确运行的原生实验；各自验证范围单独报告。

M3-C1 提供进入 C2 设计阶段的工程基础。若 C2 目标包含排队后第二名患者治疗，必须先独立设计和验证合法时序、评价适用性及资源反馈协议；本轮没有实现或自动进入 C2。

实验 run_summary 在独立核验前保守记录 PARTIAL；最终阶段状态以只读 `m3c1_accept` 对真实模型和双向原生 baseline 的聚合验收报告为准，不回写原始运行证据或历史run。
