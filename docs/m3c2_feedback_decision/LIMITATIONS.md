# 适用范围与未完成项

本轮分开验证真实反馈控制与独立时序探索。真实反馈实验使用旧180秒协议、固定A优先与真实反馈LLM；独立时序探索使用新协议、固定优先级及Fixed反馈baseline，不声称是同一次真实LLM驱动的双患者延迟治疗。

真实模型的实际分支必须按原文报告。WAIT后若模型DEFER/STOP，宿主不得偷偷RECHECK或提交治疗；RECHECK的离线和探索baseline证据不等于真实模型已选择并验证该分支。最多两轮，DEFER终止本轮后续尝试，没有自动反馈无限循环、替代治疗、多动作DAG或一般性的自主协商。

动态协议只针对冻结StandardMale、60秒RightLeg外出血.4、一个固定控源动作，候选时点仅180/181。后者为独立探索；182及任意其他治疗时间仍拒绝。180/181选择不是临床推荐，1秒确认策略也不代表实际医务人员操作时长。

新路径复用原执行器所有非时间检查，默认旧路径仍180。两个spawn进程独立状态；屏障不是两个引擎的可回滚原子推进。通讯/执行Unknown保留资源隔离并停止，不能根据LLM语言猜测执行结果或重试治疗。

探索动作accepted只证明提交被接受；还需要后续原生源机制确认和身份/资源核验才能称技术执行通过。即使两个患者都完成探索控源，也没有验证医学疗效、排序优越性、动态策略比较或可泛化的延迟时序。

旧14规则、StandardMale/Soldier、匹配control、独立执行证据、评价时间窗仍有限制。181秒治疗至480只有299秒，不能伪装旧180—480窗口。探索不调用硬编码180的旧manifest构造器，明确NOT_EVALUABLE，不产生正式E/P/I。完整动态治疗有效性仍M3C2_TIMING_NOT_VALIDATED。

进入可比较的完整动态双Agent实验还需要：预声明研究假设、异质但合法的病例与策略、匹配control/可评分协议、经过验证的治疗时间窗与多轮状态机、失败归因和预算方案、重复试验与统计设计。M1资源令牌的临床规格与治疗时长也不能由本轮推导。

没有修改M1/M2权威库存、正式配置、12动作参数、14规则、患者SHA、C1优先级语义或历史run；没有Unity、运输、多动作优化或人工签署门控。26项旧原生integration未跑时单独报告，新的原生实验不冒充它们。
